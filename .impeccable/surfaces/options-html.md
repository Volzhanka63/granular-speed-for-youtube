# Settings, welcome and in-player panel

Scope: extension settings page (toolbar popup and about:addons), welcome page opened on install, and the in-player speed panel with its settings page. Mode: Operate (settings, panel); the welcome page is a short Read surface that ends in a working demo.

Task: set speed and its step model quickly; change settings rarely, sometimes mid-video. Constraint: inside the YouTube player, YouTube's own menu language wins (measured: 330px, 40px header, 48px rows, 32px round controls, 60% black, 12px corners).

## Direction contract


FORM: seed:4c5bedcf8960f796 (assigned index 7, instrument cluster; the user picked it over the engineer's-scale pick after seeing both built).

THESIS: the settings are an instrument for one number. They refuse the default stack of bare number inputs in favour of a live speed scale plus steppers.

OWN-WORLD: graphite (#111214 / #1b1c20) at night, cool grey (#e7e8eb) and white by day; amber #ffb020 reserved for live values only (fine-step zone, switch-point needle, primary action, focus). System sans, one 14px size, weight for hierarchy, tabular numerals in fixed-width value cells. Round steppers and pill chips.

STORY: you see every speed you'll step through, then adjust the two step sizes, the switch point, the range and presets, each change redrawing the scale.

FIRST VIEWPORT: header, then the speed scale card with count, then Steps.

SIGNATURE: the speed scale, ticks per reachable speed, fine zone lit amber, draggable switch-point needle (keyboard: arrows).

RAISES: every setting shows its consequence live (from monochrome-product challenger); one type size does the work (acetate manual); corrected values are marked in place, never silent (ticket wallet); amber reserved for the active layer (orienteering); fixed numeral cells so nothing shifts (split-flap).
